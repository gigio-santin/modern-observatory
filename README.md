# Modern Observatory

Explore o winners metagame de Modern nas listas publicadas dos Challenges MTGO e de RCs, RCQs e Spotlight Series disponíveis no MTGTop8.

https://gigio-santin.github.io/modern-observatory/

A cobertura varia por evento e não representa todos os inscritos. A distribuição usa o período selecionado inteiro; cada ponto temporal usa a respectiva semana. Nomes são padronizados pelo projeto, com classificações automáticas sinalizadas.

Dados são carregados sob demanda. Projeto pessoal, sem vínculo com Wizards of the Coast, Daybreak ou MTGTop8. Fontes e limites estão disponíveis no site.
