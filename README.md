# Modern Observatory

[Abra o site](https://gigio-santin.github.io/modern-observatory/)

Projeto pessoal para explorar 96 listas publicadas de três Challenges Modern do MTGO, de 22–23/09/2026. Inclui arquétipos, resultados, main deck, sideboard e cobertura da amostra. Não representa todo o metagame nem todos os participantes dos eventos.

O site é estático, sem cadastro. Compartilhe o link pelo WhatsApp e abra no navegador. O HTML também contém todos os dados para consulta local em navegadores que executem JavaScript; prévias de anexos do iPhone podem não executar a interface.

A classificação dos arquétipos é própria, com ambiguidades sinalizadas. Fontes e datas aparecem em cada evento. Projeto sem vínculo oficial com Wizards of the Coast, Daybreak ou MTGO; nomes e marcas pertencem aos respectivos titulares.

Este repositório contém somente a versão publicada (`index.html`), este README e `.nojekyll`. A atualização é manual; o Pages publica a raiz de `main`. Não há coleta automática ou promessa de atualização diária.
