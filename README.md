# Modern Observatory

[Abra o site](https://gigio-santin.github.io/modern-observatory/)

Projeto pessoal para consultar listas publicadas em Challenges Modern do MTGO. O site informa a quantidade de eventos/listas, o período disponível, as fontes e a cobertura de cada evento. A base não representa todos os participantes nem todo o metagame.

Inclui filtros de período, evento, Top 8/Top 16 e arquétipo; busca por jogador ou carta; consulta de main deck e sideboard. A classificação é própria: sugestões novas são provisórias e casos não classificados permanecem explícitos. A paginação limita a exibição, mantendo cálculos sobre todos os registros do recorte.

Compartilhe o link pelo WhatsApp e abra no navegador. O HTML também contém os dados para consulta local em navegadores que executem JavaScript; prévias de anexos do iPhone podem não executar a interface. Não há cadastro nem atualização automática da base.

Projeto sem vínculo oficial com Wizards of the Coast, Daybreak ou MTGO. Nomes e marcas pertencem aos respectivos titulares.

Este repositório contém somente a versão publicada (`index.html`), este README e `.nojekyll`. O GitHub Pages publica a raiz de `main`. As atualizações são manuais e validadas antes do envio.
