04 / LEITURA DOS DADOS

O que este arquivo mostra

Versão estática com 96 listas publicadas dos Challenges Modern do MTGO. Não há atualização automática, win rate, conversão para Top 8 ou inferência sobre o metagame global. A data do evento é reproduzida da fonte, cujo fuso não foi informado.

As posições são as colocações finais publicadas; posições iguais são preservadas. O registro V–D da fonte tem fase não confirmada e não é usado para calcular taxas. As listas cobrem as posições 1–32 de cada evento; não temos as listas de todos os participantes nem partidas completas.

A fonte não forneceu nomes de decks nesta amostra. A taxonomia própria foi revisada pelo assistente a partir das cartas; não foi validada por especialista humano. Variantes ambíguas estão sinalizadas e continuam no denominador. Cartas de mesmo nome e edições distintas são somadas na exibição, mantendo main deck e sideboard separados. Companion não foi identificado pela fonte.

Projeto pessoal, sem vínculo oficial com Wizards of the Coast, Daybreak ou MTGO. As listas e os resultados vêm das páginas públicas indicadas em cada evento. Os nomes de arquétipos são uma análise própria. A página não consulta serviços externos automaticamente; os links “Fonte MTGO” exigem internet.
